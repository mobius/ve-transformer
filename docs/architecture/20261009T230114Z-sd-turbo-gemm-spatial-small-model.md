# 第95轮架构：保留基线的按形状分块

显式mixed4096仍只进入既有五形状VAE FP32矩阵分块路径，线程数为4。选中256×65536×2304及256×65536×4608时block=4096，其他block=8192；输出ldc与输入偏移不变，日志按实际block计算调用数。原有8192路径及不分块回退保留。

检查器按实际形状/分块核验9个图节点，mixed4096对应168次库调用（五个选中前者节点各16次、后者1节点16次，其余72次）；none与8192保持原核验。模型为单VE官方SD-Turbo FP32，候选默认关闭，完整请求速度待后续实测。

双请求83.449651/9.064277s；六提示冷83.893102s、热9.064508/8.908026/9.043425/9.003133/8.974348s；四步重试90.023814/16.257247s。62CPU/10PNG通过，全部输出与第92轮逐字节相同。只有BLAS对象和对应静态库变化，其余42对象/库不变，实际9节点/168调用。首轮四步因CPU85°C停止、无完整请求耗时，25文件快照保留；冷却到CPU66°C/VE55.25°C稳定10秒后单独重试通过。成功运行CPU最高79°C/VE最高67.38°C，各97风扇通道变化0、BMC不可读。完整请求增量收益待下一轮同二进制ABBA，不因验证耗时低而宣称改善。
