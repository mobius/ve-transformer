# 迭代 007：温度监督架构

temperature_guard.py 使用标准库，在主机发现 coretemp 和 VE1 已确认的温度通道，执行启动前检查，创建独立任务进程组，然后定期采样并记录。保留原命令输出和退出码，温度保护失败返回 125。

超温、读取失效、用户中断及终止信号时向本次进程组发送终止信号；等待最多 2 秒后清理仍存活的同组进程。不关闭系统服务，不改风扇/频率，不终止其他任务。任务正常退出也清理同组遗留子进程。

保护是软件监督，有采样延迟；驱动清理卡上任务可能另需时间，不替代硬件热保护。只验证当前 VE1 温度映射，其他型号明确拒绝。日志只包含时间、传感器标签、温度和停止阈值，不保存完整命令/环境或账户路径。
