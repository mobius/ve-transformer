# 图像算子与完整模型的验证边界

隔离图像框架、图像 ggml 和 NLC 位于项目构建目录；LLM 的框架、环境及默认入口不变。主机负责编译、启动、读取参考文件和比较；原生图像进程及其 BLAS/通用后端在 VE 内执行。后端名称 CPU 指通用原生执行器，不能据此推断主机卸载。

基础算子验收已完成，包括真实首层卷积和文本矩阵尺寸，以及奇数尺寸边界；没有将这些结果外推为完整 U-Net/VAE 正确性或性能。

完整模型通过固定噪声、文本嵌入、每步网络输入/预测、潜在数组和归一化 VAE 输出逐级比对。数组以连续 FP32 存储，轴顺序明确；每个参考 raw 文件有尺寸及 SHA256。测试导出开关默认关闭，写入失败、维度错误和非有限噪声拒绝。

原生和参考的 Euler 调度噪声强度直接共享；epsilon 预测与单正向条件路径一致。卷积展开保持 FP32，GELU 使用 erf 公式。保留完整 im2col 作为首轮正确性基线，尚无工作区分块或物理 HBM 峰值测量；后续须由真实分配和性能数据决定优化。

平台能力边界：当前 VE 构建明确禁用模型格式转换，两个公开转换 API 返回失败并说明原因，不能据此宣称通用转换或量化已移植。官方目录读取、权重驻留和所有神经网络阶段仍需完整实跑验收，禁用转换不改变其标准。CPU 构建保留上游转换代码。

覆盖头文件在框架目标的 include 查找顺序中优先，统一全部图像框架单元，避免混用不同 GroupNorm32 定义；原始工作树不变。稳定常数属于模型配置，按层对齐；独立算子使用与框架一致的张量布局宏。构建清单记录所有生成头文件及精度适配源码的 SHA256。

自动检测修图与基础文生图分开：VE 一期构建明确不提供前者，创建接口拒绝、修图接口失败并清空输出；CPU 构建保留。构建清单记录可选能力标志，不能将这些拒绝接口当作功能验证或模型执行替身。
