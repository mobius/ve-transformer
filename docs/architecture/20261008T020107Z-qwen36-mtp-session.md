# 原生 MTP 常驻会话与收益回退

硬件环境：96 个逻辑 CPU、三张 VE1，槽设备与 VEOS socket 可读；实际执行仍须本轮守护验证。ASPEED 为显示控制器。使用已有项目环境，不安装全局软件。

本轮目标：沿用长度前缀协议，模型和 FP64 缓存驻留，逐请求清理 KV/递归状态；可选自动策略在当前请求观察草稿轮次成本，收益不足时回退普通生成。策略默认关闭，不改变已有客户端默认执行器。功能及性能结论须以实际测试为准。

验证计划：同进程不同提示及重复提示与已有 CPU 贪心参考比较；普通/MTP/自动策略分别检查；短帧与越界帧拒绝；使用温度守护持续观察风扇。

协议：8 字节头为两个小端 uint32，依次表示 UTF-8 正文字节数与最大输出数，随后为完整正文；输出为单行 JSON。服务器仅使用 stdin/stdout，不开启网络监听。独立 CLI 的 --repeats 保持可用。

自动模式先执行一个普通目标解码步骤作为单位词元参考，并用真实目标隐藏状态追赶草稿，之后才允许提出候选。至少三轮后，比较累计草稿、验证、追赶与回退成本除以这些轮次实际推进的词元数，与普通解码的单位成本；超过参考就停用草稿直到请求结束。下一请求重新清空状态并重新估计，不继承上一请求的关闭决策。停用时目标状态已回退到接受位置，所以可直接普通解码；不会使用过时草稿状态。该策略仅有一个标量成本参考，短请求和测量噪声可能影响决策，暂不作为默认策略。

用户追加图像/视频生成适配评估：已查官方模型和 VE 卡型资料，结论见 `docs/research/20261008T020701Z-ve-image-video-feasibility.md`。这是可行性研究，未下载或运行生成模型；现有常驻推理验证继续。优先算子测量和低分辨率图像基线，再考虑视频。

## 最终功能验收

普通、固定 MTP、自动 MTP 三个常驻进程，分别按代码/中文/算术/代码发送四个请求，每请求强制 12 个词元；共 12 个请求均与独立已保存 CPU 贪心参考相同。重发代码提示验证跨请求重置；越界正文长度、半头部、半正文三个异常帧均有明确报错且非零退出。原生模型与新二进制哈希、测试脚本快照、各样本指标已归档。此轮不是新增全词表分数、最大上下文或其他运行槽验收；自然 EOS 和扰动全部拒绝的原生核心证据属于上一轮二进制，不把它们描述为本轮新增测试。

自动策略在所测中文请求经过三轮后关闭草稿；代码请求保留草稿，且下一请求重新估计。实际观测末次热态代码普通/固定/自动约 0.593/0.880/0.783 词元/秒；中文约 0.596/0.537/0.562。只有单个相应热态样本且按模式顺序执行，不是交替性能基准。自动模式虽回退，仍有此前草稿开销，中文仍慢于普通；代码也低于固定 MTP。因此自动策略仅完成实验功能验证，未采用为默认，不声称额外性能提升。

常驻普通模型启动约 18.114 秒、固定/自动 MTP 约 34.101/34.330 秒；该成本在进程内只付一次。代码首次与重复请求的主机往返时间普通 75.274→28.202 秒、固定 MTP 69.554→21.780 秒；首次还包含权重缓存填充，不能把差值全部归因于会话协议。原生行内 load_seconds 是进程共享的加载统计，不能每请求再次累计。

测试最高 CPU 76°C、VE0 57.12°C、VE1 43°C、VE2 45.38°C。风扇/策略观测通道计数 97，零观测变化，部分通道与 BMC 不可读，不能证明实际风扇策略未变化。未调整散热配置。

公开验收见 `docs/results/20261008T020107Z-qwen36-mtp-session.json`。客户端引擎路由、非思考聊天格式及非法参数检查通过；原有默认执行器选择检查通过。下一步自动策略性能研究需更长输出与多个提示做正式交替基准，避免短请求校准成本主导；本轮结束硬件测试，优先按用户指示进入图像方案。

图像阶段具体里程碑见 `docs/plan/20261008T021318Z-sd-turbo-ve-stage.md`，以 SD-Turbo 单步 512×512 为首个完整模型，先部分去噪核心、再完整神经网络，之后分项优化及现代 DiT。当前只制定方案，未实施图像移植。
