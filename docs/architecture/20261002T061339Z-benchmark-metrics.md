# 迭代 003：基准数据结构

推理计算代码保持不变，测量入口接受位置数、特征维数、头数、前馈维数和重复数。参数严格校验并限制最大值，避免不受控分配。权重和输入初始化仍确定性生成。

每次调用前后读取单调时钟，保存各次延迟并排序计算最近秩 P50/P95。总计时计算平均延迟与输入位置吞吐量，包含读时钟和临时分配开销。预热及程序启动、编译均不计入调用耗时。

benchmark_sweep.sh 为 CPU 及各运行槽位执行完全相同的形状和重复数，创建带 UTC 时间戳的结果文件。各形状与设备顺序运行，不实现多卡协同。

保持“正确性示例”与“较大规模性能基准”的验证强度区别：前者有独立逐元素参考，后者暂只有有限性和校验和。后续算子替换必须补充更大形状的数值验证。
