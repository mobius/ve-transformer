# 已完成图像推理路径

原生VE进程完成CLIP分词/编码、UNet去噪、Euler调度、VAE解码与PNG输出。主机负责官方来源校验、张量索引准备、启动及独立CPU参考/输出对照。参考计算不属于实际VE推理计算路径。三网络通过NLC矩阵后端与原生VE通用算子后端执行，CPU后端名称在该VE二进制中表示原生VE通用执行后端。

组件顺序加载释放，四步复用UNet权重；工作数组在原生VE进程中维护。旧兼容基线采用分开的CLIP/UNet/VAE编译单元以避开本机NCC整体流程编译崩溃。数值核O1/F32/NLC，元数据与模型编排C++11/O0/禁内联。现代框架移植实验仍未完成。

验证范围限定单VE、官方固定修订SD-Turbo、FP32、512×512、1或4步、固定噪声/调度及六个短提示。固定入口不提供完整上游SDK或通用生产服务；三卡协同、其他分辨率/模型、视频、现代DiT、物理HBM峰值及稳态性能未验证。
