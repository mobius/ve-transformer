# 精确RGB打包模型架构

仅将sd-pixels-ve目标源切换到ve_sd_turbo_pixels_pack.cpp。原有位模式扫描/钳制保留，打包保留float32乘255，使用整数截断和精确可表示的半整数阈值；内部前提是已经钳制到有限0–1的像素，模型审计逐请求检查此条件。追踪、PNG调用、RGB缓冲复用和默认generic路径不变。

实际对象与独立测试对象SHA一致；模型数学计算、分词、采样和PNG在VE上，CPU用于独立参考核验。新旧构建使用相同神经核、主程序O0和PNG O2，下一轮只比较像素目标替换；两二进制链接布局不同，冷缓存无法严格控制。

所有硬件测试与CPU数值审计持续温度保护：CPU警告/停止80/85°C、VE70/75°C；编译50%占空比、核心0–3、单任务，CPU审计25%占空比、单线程数值库。阈值为项目策略。
