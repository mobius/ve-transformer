# GatedDeltaNet 状态一致性迭代

GatedDeltaNet将历史状态按门控衰减，再根据键和值更新状态，最后以查询读取输出。本实验用双精度中间计算统一CPU/VE路径，状态仍为单精度；保留槽0为最近状态以及未使用快照槽的调用方内容。仅实验精度路径启用，不改固定版本上游源码。

CPU与VE真实运行合计188项检查通过，包括16项状态更新检查。受保护构建退出0；CPU峰值74°C，ve0峰值48.12°C，读取104风扇通道，3项观察到变化，部分风扇4500→4600 RPM。日志build/qwen-accurate-delta-build-check.log。随后启动新真实模型节点采集。
