# 迭代 006：VTF32V1 与 PyTorch 桥接

VTF32V1 文件为小端：8 字节 magic（VTF32V1 加零），5 个 uint32 表示位置数、特征维、头数、前馈维、因果标记；随后是 float32 的 Q/K/V/输出矩阵、FFN 两矩阵、第一层 gain/bias、第二层 gain/bias、输入。矩阵均按行存储。输出为 t×d 个 float32。

执行器限制形状最大值，精确检查载荷长度、尾随数据、有限性与输出长度；失败返回非零。每次调用的临时文件在项目 build 内自动清理，不写全局路径。当前只支持 CPU 与 VE 的小端环境。

python/ve_transformer.py 验证框架语义，导出权重，使用参数列表调用原生程序，不用 shell 拼接命令。返回主机 CPU Tensor。该路径不是 torch 原生 VE 后端，不支持梯度。

两层示例将 Transformer 层放在一张指定 VE，嵌入与输出头留在主机，依次验证三个槽位，不涉及卡间通信。
