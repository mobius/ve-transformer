# 迭代013：从GPT-Neo到Qwen3.6的差距

现有执行器：float32、LayerNorm、GELU、GPT-Neo局部/全注意力；全部历史序列重复前向，embedding和输出头在CPU。常驻协议解决进程与权重反复启动，但未解决现代模型的状态与精度。
目标文本执行路径：模型权重常驻且分块低位读取；VE增量执行；全注意力维护KV缓存，Gated DeltaNet维护循环状态；RMSNorm、旋转位置编码、门控激活和前馈；35B-A3B还需MoE路由、稀疏专家及共享专家计算。输出头约25万词表，需独立测量是否留CPU或移VE，不能直接沿用小模型选择。
安全加载需要重新设计大模型参数计数与容量限制，而非直接删除现有上限。48GB级预算须保留工作区、缓存与系统余量；整模型展开float32会超容量。三卡以后需明确切分策略及主机通信成本。
