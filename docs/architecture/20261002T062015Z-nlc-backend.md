# 迭代 005：可选 NLC 后端与参考设计

VT_USE_NLC 仅替换线性变换：Q、K、V、输出投影和 FFN 两层使用 NLC cblas_sgemm；其他运算保持相同基础 C 路径。不同二进制明确区分 base/nlc，不隐式改变原实现。CBLAS 维度转换前限制在 INT_MAX 内。

主机参考分三级：标准库 float64 小示例；独立 NumPy float64 多形状参考；现代框架 PyTorch float64 模型参考。CPU C 程序是基础实现，不是精度 oracle。大形状对比以 NumPy 参考为准，CPU 自身误差同时打印以便诊断。

NLC 基准配置 OMP_NUM_THREADS=8、OMP_DYNAMIC=FALSE，节点依次运行，避免三卡同步饱和。基准仍包含每次临时内存分配，排除进程启动和导出，不宣称框架端到端速度。
