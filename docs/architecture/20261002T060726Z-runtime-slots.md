# 迭代 002：设备访问与验证入口

硬件信息：/sys/class/ve/veN → 仅用于枚举物理硬件。

执行路径：运行槽位编号 → /dev/veslotN 链接及对应设备 → /var/opt/nec/ve/veos/veosN.sock → ve_exec -N N → VE 原生程序。

这两类编号不可凭相同数字建立映射。包装脚本的 Offline 消息可以来自缺失的 veslot 链接，不能当成已查询硬件状态的证据。

scripts/validate_ve.sh 独立负责环境检查、构建、逐卡正确性验证和基准。tests/check_reference.py 支持命令前缀，既可直接运行 CPU 二进制，也可通过 ve_exec -N 调用 VE 二进制。原有计算 API 不变。

设备验证以实际执行结果为准。无需使用 systemctl 作为前置硬条件，避免把沙箱不能访问系统总线误判为宿主机服务停止。暂不引入 AVEO 或多卡通信。
