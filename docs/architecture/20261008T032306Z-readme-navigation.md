# 项目文档入口架构

README承担项目首页：简要能力范围、最短验证入口与导航。docs/README承担文档索引：按模型使用入口、公开报告和目录职责。

docs/guides保存当前使用步骤及必要限制，按模型拆分，避免首页累积每轮实验日志。docs/results保存经过隐私筛选的结构化验收数据。research/plan/impl/architecture继续保存带UTC时间戳的每次迭代，不改写历史失败或旧性能口径。

原README全文归档为research历史记录，以完整保留迁移内容；归档中明确早期状态不代表当前能力。文档迁移只改变信息位置和入口，不改变计算架构、默认执行器或数学路径。
