# Qwen3.6 单卡性能判断

环境依据：当前 NEC VE 单卡模型测试已实际执行，CPU/VE 温度守护持续运行；显示 GPU 不参与计算。本次仅记录和分析已有结果，不安装软件或启动额外负载。

实际模型为 Qwen3.6-35B-A3B 的 UD-Q4_K_M 文本权重，约22.13 GB，测试上下文配置4096。当前精度通过的路径使用 FP64 累加；三组提示共36步完整词表误差检查及重复运行检查通过。这不是所有输入的精度保证。

正式扫描中，1/2/4/8线程的热态生成速度分别为0.361515、0.485214、0.4709295、0.5096355词元/秒。8线程在本次短输入测试最快，相比同精度未缓存基线0.103475提高4.925倍。21词元输入热态预填充9.896秒，首次45.446秒，另有约18秒模型加载。已完成的260词元输入热态预填充99.093秒、生成0.494542词元/秒。更长输入测试仍运行，不能宣称最终扫描完成。

据已测生成速度0.49–0.51词元/秒估算，生成100词元约196–204秒，200词元约392–408秒；不含输入处理、加载及其他服务开销，也不是字符或汉字速度。当前可作正确性与移植验证，交互延迟较高。

曾测约1.46词元/秒的快速路径未通过精度门槛，不作为可用性能。不能从早期小型Transformer或三张卡数量线性外推该模型吞吐，也不能承诺优化后达到某个未测速度。

数据：build/results/20261002T162100Z-qwen-final-bench/progress.json。下一步保留正在进行的长输入测试，待其完成后统一报告最终性能和温度/风扇证据。
