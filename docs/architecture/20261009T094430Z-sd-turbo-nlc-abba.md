# SD-Turbo统一线程交替性能对照

上一轮获得实测进展：统一固定8线程候选通过双请求、六提示、四步共62项CPU阶段检查，热请求一步18.20–18.36秒、四步30.24秒，但尚未正式交替性能对照。本轮保持输入/当前检查器一致，顺序NLC通用pthread基线A，与NLC/通用统一OpenMP固定8线程候选B，执行A/B/B/A，明确两个不同二进制，不声称同二进制。

环境：宿主96逻辑CPU、ASPEED显示、三VE槽设备及VEOS套接字可见，NCC/ve_exec可用，前轮候选实际运行；没有旧重型测试。实施前温度/风扇守护查询正在执行。原始构建完整归档，检查器增加只读build目录归档支持，逐文件SHA核验并拒绝越出快照路径。新基线仍须守护构建和执行验证。

固定SD-Turbo FP32、512、一Euler步、VE槽1、常驻权重/分词器、原SiLU/Softmax/im2col；冻结CPU参考，不重新生成。全部运行串行，持续CPU/VE温度、风扇及节点内存监控。每臂双请求、各运行两次；阶段CPU数值检查必须全过，输出舍入差异记录而非预先要求逐字节相同。报告冷/热/进程均值及收益，温度、风扇、内存与局限。尚未测量正式收益。
