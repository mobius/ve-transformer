# 迭代 012：resident-worker

主机保持分词、嵌入、位置和最终输出头。VE常驻进程一次加载全部8个Transformer块，进程内连续执行，消除逐层往返；请求以有界二进制标准输入/输出传递特征，完整或最后一位置输出。权重和最大序列容量固定，会话不缓存生成结果；独立会话无共享状态。工作进程继承温度监督进程组，避免逃离热保护；超时关闭当前会话。

权重bundle：8字节VTGPTN1魔数+3个LE uint32（层数、特征维、最大位置数），随后每块合法v2文件（t=1，末尾占位输入不用）。限制层数1..32、宽1..2048、位置1..1024、FFN1..8192、总张量最多64M个float；所有块head/FFN形状统一以共用工作区。只导出块权重，主机嵌入和头未移到VE。

启动响应VTREADY1+double加载ms（16字节）。请求为2个uint32（位置数、是否只返回最后位置），随后tokens*width个float；tokens=0且flag=0正常关闭。响应VTRES01魔数+status、output_tokens两个uint32+double计算ms（24字节头），随后浮点特征。当前错误以进程非零退出/EOF表示，主机关闭损坏会话。默认15秒读写超时，非阻塞管道配合select；启动/请求故障清理进程和临时文件，不保存任意错误输出到提交文档。会话不支持并发调用，调用者使用with或显式close。追踪仅保留最近256次请求。

容量工作区支持1..max_tokens，其他维固定；旧创建接口保持严格形状。只分配一次双输入/输出缓冲区，每层交替指针，最多一次请求往返。默认线程1限于该小模型，可显式选1..8；不改变全局线程配置。进程继承监督进程组，不能独立脱离温度保护。
