# 迭代 008：NLC 矩阵注意力

fast 是独立可选编译后端，定义 VT_USE_NLC 与 VT_NLC_ATTENTION。每个头按 scale×Q×K转置计算分数，对每行做稳定 Softmax，再用概率矩阵乘 V。CBLAS 的行跨度设为完整特征维数，直接访问交错头布局，避免头数据打包/转置副本。

所有头复用一张 t×t 分数矩阵，因果模式归一化时只使用允许位置，未来列明确清零后再乘 V。该版本仍计算完整 QK 矩阵，没有实现分块或因果三角计算。分数缓冲区从 t 个 float 增至 t² 个 float；新增溢出检查。t=1024 时增量约 4 MiB。

vt_forward_profile 提供每次调用的分项时间，不持有全局状态；vt_forward 委托同一实现但传空 profile，不读分项时钟。benchmark 的 --profile 仅用于诊断，性能对照默认不启用。

默认形状检查用独立 NumPy float64，CPU 漂移诊断可按需启用，减少重复执行低效 CPU 基础实现产生的热负载。温度保护优先于测试进度，超温导致的中止不得作为功能通过。
