# 迭代 009：设备阈值和风扇侧车日志

温度记录每行包含 CPU/VE 对应警告及停止阈值。CPU 标签选择 CPU 策略，其余 VE 温度标签选择 VE 策略。旧共享阈值参数只在明确传入时覆盖对应默认值。

风扇是观察信号，单独写与温度日志同前缀的 fans.csv，避免把 PWM 数值、RPM 或服务状态当作摄氏度。记录原始值和不可用状态，跟踪本次观察期内变化，摘要不把开始/结束相同当成没有中间变化。系统服务仅记录白名单状态字符串，不保存任意命令或服务配置。

主任务结束时清理其进程组，可按 post-seconds 继续温度/风扇采样，观察冷却，不启动额外负载。风扇信号缺失不改变温度停止策略。

Python 3.6 读取暂时不可用 sysfs 文件可能抛 TypeError；温度采样统一转换为读取不可用并停止，风扇采样则标记 unavailable。避免可选的风扇读取错误使监督器崩溃或留下任务。

可选BMC采样固定执行sudo -n ipmitool sdr type Fan，只提取风扇名称和RPM，不保存完整命令输出或认证信息。每约5秒读取一次，3秒超时，权限缓存受终端范围影响。查询耗时会延长温度采样周期；不可用状态明确记录，不能据此宣称实际风扇不变。
