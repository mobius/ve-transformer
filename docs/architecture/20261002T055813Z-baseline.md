# 迭代 001：基础架构

同一 C11 计算实现分别由 GCC 编译为主机程序、NCC 编译为 VE 原生程序。CPU 提供可运行的正确性基线，VE 只确认编译，不以 CPU 运行替代设备验证。

计算路径：输入 → LayerNorm → Q/K/V 线性变换 → 分头缩放点积注意力及稳定 Softmax → 输出投影 → 残差相加 → LayerNorm → 两层 FFN/ReLU → 残差相加。

权重由调用者提供；形状为位置数、特征维数、头数、前馈维数。没有隐式随机状态，不依赖外部框架，不进行设备间通信。每次调用分配临时数组；这是容易验证的设计，暂不追求最优性能。

矩阵乘法把连续输出维放在内层以方便向量化。注意力逐个查询位置计算，仅保存一行分数，临时存储没有位置数平方的矩阵，但运算仍随位置数平方增长。支持双向与因果两种注意力。

当前只是一层推理运算，不是完整语言模型；词元嵌入、位置编码、多层网络、输出头、文本分词和权重加载待下一阶段设计。三卡独立执行与多卡协同是不同能力，目前两者均未验证。
