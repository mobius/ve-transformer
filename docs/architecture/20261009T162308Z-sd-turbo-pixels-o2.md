环境预检：96 逻辑 CPU、ASPEED 显示、三 VE1，NCC 和 ve_exec 可用；CPU 66°C、VE 最高 47.62°C，97 个可读风扇状态未见变化。设备枚举不等于执行验证，本轮独立 VE 实测确认。

设计：将原像素钳制和三通道打包表达式提取为隔离 O2 核，主程序保持 O0。保留有限值检查、失败前已写入前缀、float 表达式、std::round 与通道布局；钳制和打包之间原追踪边界不得融合。默认关闭接入，独立验证先行。

测试：原 O0 参考和 O2 候选使用相同输入，完整比较钳制 float 字节与 RGB 字节；覆盖小尺寸、非向量宽度尾部、512×512、随机/极值、舍入边界、非有限值及六个 CPU 参考模型的真实 decoded 浮点输出。记录真实浮点来源，不称为原始 VE decoded。有限值场景四臂每臂一预热三测量，单独比较钳制与打包。所有编译与运行温度守护，编译 25% 占空比；无软件安装。

结论待实测；独立核收益不能代替完整模型收益。下一步通过后接入默认关闭开关、多样模型验证、同二进制正式对照。

## 本轮实测结果

实际运行单 VE，原 O0/-fno-inline 参考与隔离 O2 候选，使用严格浮点选项。每输入四臂一预热三测量，六个原始 CPU 模型 decoded 输入（每个 512×512 三通道）的平均结果：

| 独立阶段 | 原 O0 参考 | O2 候选 | 延迟降低 |
| --- | --- | --- | --- |
| 像素钳制 | 79.916389 ms | 32.979722 ms | 58.73% |
| RGB 打包 | 88.689167 ms | 39.551917 ms | 55.40% |

27 组钳制 float 和 18 组 RGB 完整 CPU 字节检查通过；VE 初始及 288 次钳制/打包计时调用均完整对照 O0 参考并检查边界哨兵。9 组非有限输入验证首个异常位置及先前写入前缀，7 项无效参数检查通过。六个真实输入来自已核验 CPU 模型参考 decoded，不是原始 VE decoded。

编译器报告两个候选循环未向量化：钳制的提前退出限制优化，打包仍未形成向量循环。当前收益来自隔离 O2 编译路径，不能归因为向量化；完整模型尚未接入，不能声称整图加速。保留编译器诊断与实际对象摘要。

运行与编译温度 CPU 最高 69°C、VE 最高 49°C；独立 CPU 审计最高 CPU 63°C、VE 47.25°C。97 个可读风扇状态无变化，BMC 不可用，物理策略不能断言。未触及警告/停止阈值。

审计脚本初次语法检查发现字典推导式缺括号，已修正并重新通过；首次语法检查不产生数值结论，随后完整 CPU 审计成功。

结论：独立核正确性及性能验证通过，模型速度未测量。下一步接入默认关闭 SD_VE_PIXELS 开关，保持追踪边界、PNG O2、RGB 复用及原模型编译级别；新构建双请求/六提示词/四步 CPU 参考和输出字节验证后，做同二进制四臂正式对照。
