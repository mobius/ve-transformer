## 本轮独立实测结果

相同严格 O2 选项，基线为已验证原像素源码（仅编译时重命名符号用于同二进制对照），候选为独立文件。六个原始 CPU 模型 decoded 输入，每输入每模式六次正式测量，先预热，再四臂交替：

| 阶段 | 本轮 O2 基线 | 循环重排候选 | 延迟降低 |
| --- | --- | --- | --- |
| 钳制 | 11.497500 ms | 8.428555 ms | 26.6923% |
| RGB 打包 | 39.562167 ms | 33.008556 ms | 16.5653% |

两阶段平均合计节省约 9.623 ms，仅为独立核收益；相对整请求耗时占比很小，不据此宣称完整模型提速。本轮钳制基线 11.498 ms 与此前独立轮的 32.980 ms 不同，未证明跨轮差异原因；只采用本轮同期 O2/O2 对照，不将历史绝对时间差计入收益。

完整检查：33 组 CPU float 字节、18 组 CPU RGB 字节均通过；15 组非有限输入含多个不同异常位置、NaN 位模式及最大尺寸尾部异常，首个异常前写入和异常之后所有字节保持原路径一致。7 项无效参数检查、边界哨兵检查通过，288 次钳制/打包计时调用均完整对照原核。六真实输入来自 CPU 参考 decoded，不称为 VE 原始 decoded。

编译器证据：候选第 12 行钳制计算循环 Vectorized loop；第 10 行有限值扫描和第 19 行 RGB 打包仍 Unvectorized loop。原基线两个循环均未向量化。实际源码、编译脚本、对象、二进制及完整编译诊断已记录摘要；不将打包的收益称为向量化收益。

构建和 VE 执行 CPU 最高 65°C、VE 最高 49.75°C；独立 CPU 审计最高 CPU 62°C、VE 48.38°C，采用 25% CPU 占空比及逻辑核心 0–3，运行不节流。全程未触及警告/停止阈值。97 个可读风扇状态无变化，BMC 不可用，实际物理策略未知。
