# SD-Turbo 分阶段验收边界

独立Diffusers CPU参考保存精确初始噪声和每阶段FP32数组；VE原生程序读取相同噪声及调度序列，分别输出文本嵌入、每步输入/预测、最终潜变量和VAE解码。比较的是原始数值，PNG只是可视化产物。

测试程序只在所有阶段阈值满足后写completed=true。基础算子、完整CPU参考和完整VE图像是三个独立的验证范围。完整图像验证计时包含模型加载和诊断文件输出，不能替代常驻性能基准。

模型创建模块实际触发NCC ccom SIGSEGV，构建退出2；CPU峰值78°C、VE峰值46.75°C，未触发热停止。生成独立SD2工厂覆盖文件，保留上游真实FrozenCLIP、UNetModelRunner和AutoEncoderKL构造及缩放设置；非SD2、替代VAE/音频VAE明确拒绝。CPU构建保持完整上游工厂。避免将尚未移植的现代图像/视频模型当作可运行。上游工作树不变。

本轮重新执行11项VE基础算子，全部通过；CPU74°C、VE46.75°C，97个风扇可读通道未观察到变化。证据见docs/results/20261008T042750Z-sd-turbo-validation.json。

进一步明确本轮为单图推理构建：视频生成和视频潜变量上采样入口均清空输出并返回失败。仅终止已核对父进程与源文件的本项目可选video.cpp编译，然后重新构建；该次是主动停止，不是编译器崩溃或热停止。核心图像路径不替换为占位实现。Euler诊断数组改用step-1编号，与独立CPU参考从0开始的编号一致。

主接口、分词及上采样模块随后编译完成，超分辨率功能未删改，也未验收。整图控制文件O1编译持续超过7分钟，本轮仅主动停止已核对的该编译进程，改为三个生成的流程控制/工厂文件O0与关闭内联；ggml数值内核继续O1，NLC不改动。停前CPU峰值83°C（出现80°C警告，未达85°C停止），VE约45°C；97个风扇通道未观察到变化。重试编译占空比降为50%，不修改任何硬件温度策略。该次主动停止不记为编译器崩溃。

局部COMPILE_OPTIONS修改使CMake共享flags.make新增注释，并使整个库重新编译。核对公共编译定义/选项/包含路径及生成头未变化，执行make只读依赖试运行：忽略该共享标记的时间变化后仅需编译7个尚未生成对象的文件，其中image、diffusion-engine、model-builders为O0，其余为O1。使用本地一次性MAKEFLAGS=-o复用原对象，未篡改对象内容或时间戳，未跳过源文件和头依赖检查。该缓存复用只适用于本次已核对的局部修改；从干净构建仍正常编译全部文件。

初次MAKEFLAGS中的-o未被GNU make传给递归构建，出现重复编译，已停止已核对进程。改用本地一次性MAKE命令携带-o；递归只读试运行列出的库编译仍只有7个剩余文件。该试运行不创建静态库，CLI阶段因静态库尚不存在退出2，属于试运行限制，不作为真实编译失败；随后执行真实温度守护构建。

O0与递归缓存复用后，原生整图流程仍触发ccom SIGSEGV，CPU74°C、VE约45°C，未达热停止。在进一步裁剪核心流程前，检查编译进程默认栈限制8192KiB，仅对VE编译子进程设为65536KiB有界栈并重试同一真实流程；这不改变主机全局配置，也不预先认定崩溃原因。构建manifest记录该限制。

64MiB编译栈试验仍触发相同SIGSEGV（CPU73°C），没有解决问题，撤回该栈改动。新增独立src/ve_sd_image.cpp基础SD2文生图流程，真实调用上游请求解析、CLIP编码、UNet采样及VAE解码；固定单批512×512 Euler、无引导混合，明确拒绝图生图、参考图、遮罩、适配器、缓存、LoRA、拼接/修补、分块及高分辨率二次处理。本轮不声称这些高级功能已移植。原始CPU图像流程仍保留，上游源码不改动；完整数值仍待实测。
