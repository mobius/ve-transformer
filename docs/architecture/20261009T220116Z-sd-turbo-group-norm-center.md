# 第91轮架构：有界平方暂存与顺序累加

独立后端每线程8KiB平方暂存，2048元素块必须对应完整行。O2严格核计算FP32中心化和平方，原O1调用方按行及行间FP64顺序累加。均值与组内缩放保留，源码恢复后与第90轮接受源码相同，仅CPU对象变化和新增中心化平方对象。连续性、源目标完全不重叠及安全长度检查保护候选；其他情况保留字面原循环，未测试范围不得宣称通过。

同图切换中心化候选，两模式都启用已验证缩放。静默计时后明确调用候选、比较并保存，24捕获记录关联独立CPU输出；团队证据限正确性与捕获阶段。数据及限制见[报告](../impl/20261009T220116Z-sd-turbo-group-norm-center.md)。
