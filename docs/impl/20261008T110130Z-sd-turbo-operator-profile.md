# 算子计时实施

通过覆盖生成器改造隔离的图像ggml C文件与调度器，不编辑vendor或LLM后端。可选开关SD_OP_PROFILE；三网络每次图执行前清零，图结束后一次性输出各类型汇总，避免逐节点打印。此时尚未构建和运行。

## 下一候选：独立 SiLU 内核

单步原生计时与五项 CPU 数值对照完成。UNet Softmax 44.404 秒，VAE SiLU 40.946 秒、IM2COL 38.268 秒。优先隔离逐元素 SiLU，在独立 C 文件以 NCC O2、禁止 fast-math 编译；保留同二进制的 generic/ve 开关。编译器本机帮助确认 O2 和向量诊断参数；最终效果必须以实际运行决定，不能从编译选项推断。继续串行温度监控，先算子测试，再整图与四步对照。
