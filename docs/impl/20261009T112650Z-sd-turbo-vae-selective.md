# VAE仅矩阵4线程候选

前轮相同二进制对照确认VAE全4线程热请求降低6.56%，但通用阶段增加1.21秒、矩阵减少2.12秒。本轮评估通用8线程、每个VAE BLAS图进入4并退出恢复8。共享同一OpenMP运行时，不使用旧pthread混合方案。进入VAE矩阵图要求运行时上限8，实际4线程区域核验；退出恢复8，由后续通用图核验实际8。诊断记录准备/释放成本，切换自身收益待验证，不凭探针8毫秒外推全图。

新增检查器显式--vae-blas-threads4，仅允许统一模式和通用8；默认不启用，不改变运算数学。四目录留档，构建仅覆盖BLAS/调度/CPU文件，避免修改模型头。前轮二进制/源码完整归档保留，无法用新构建冒充旧对照。

环境实施前监控预检查进行中，设备可见性与实际执行区别仍保持。持续温度CPU80/85、VE70/75、温度缺失停止，观察风扇，不改配置。构建50%占空比单任务；先双请求冻结CPU参考与人数检查，再判断是否推进六提示/四步和同二进制对照。超时由内存采样器拥有并清理进程组。未安装、未提交。
