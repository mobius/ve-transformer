状态：可关闭的逐调用计时已在VE上完成验证，尚未测量多线程NLC收益。单VE、官方SD-Turbo、FP32、512、单步两请求，固定常驻权重/分词器和共享8线程池。

BLAS后端包含调用管理和诊断输出，因此不等于库函数纯计时；诊断开销没有独立对照，不报告性能提升。首次请求92.850秒、后续22.604秒，含加载和诊断，不能与上一轮不同构建直接计算收益。两请求10项CPU对照通过，七组FP32数组及PNG逐字节相同；冷/热实际矩阵形状与调用次数集合一致。

温度保护全程有效：构建CPU70°C、VE43.25°C，测试CPU72°C、VE50.25°C；97可读风扇状态通道未变，物理转速/策略仍未确认。节点内存采样完整，结束恢复128MiB基线，离散最高约9.8223GiB，不是模型独占或瞬时峰值。

已冻结下一探针输入形状清单build/nlc-probe-shapes.json，绑定此公开计时结果SHA，只包含矩阵元数据。下一步项目内构建顺序/多线程NLC探针，按1/2/4/8线程串行测试；使用确定性输入与独立FP64采样点对照，说明采样范围，不能据采样宣称完整模型正确。完整图接入仍需独立CPU单步/四步、多提示、内存回收与性能对照。尚未实施或测量多线程候选，不安装全局软件。
