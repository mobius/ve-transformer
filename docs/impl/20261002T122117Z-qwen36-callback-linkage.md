# 迭代021：NEC回调语言链接兼容

新增nec_llama_compat.cpp提供公共C符号并转发已有context方法，显式转换等价调用约定的回调指针类型。链接辅助脚本编译并纳入该对象。初次链接温度保护正常退出但链接失败：CPU79°C、VE39.25°C，104通道无观测到风扇变化；该失败没有启动任何整模型执行。

回调适配已成功链接原始VE执行器，随后优化量化执行器发现generic符号不存在。nm确认无架构模式将generic源码名称映射为公开点积符号，已将替换目标改为实际公开符号。与此同时原完整CMake库构建正常退出0，原模型功能与Release配置保留；后续使用该原完整库，不采用-O0实验库。聚合初始化独立实验不采用，主动取消，不能宣称提速。
