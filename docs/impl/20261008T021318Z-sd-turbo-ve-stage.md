# 图像模型实施状态与拟定产物

本轮仅形成实施方案，未下载图像权重、安装依赖、移植算子或做 VE 图像性能测试。首选 SD-Turbo，来源与技术判断见同时间戳 research；里程碑和验收门槛见 plan；主机/VE 分工见 architecture。

拟定产物为模型准备/哈希清单、独立 NCC 构建脚本、CPU 参考导出器、VE 算子与单步验证器、完整图像 CLI/常驻入口、温度守护下的交替基准脚本和公开汇总。文件名称在 P0 根据固定上游接口确定；不把拟定产物写成已实现。

公开文档只保留公开提示定义、输入哈希、数值/耗时/容量/温度统计与固定来源；实际图像及模型权重在忽略目录，提交前继续隐私审计。CPU 参考工具如需新包，优先独立项目 uv 环境，避免改变已验证 LLM 环境依赖。
