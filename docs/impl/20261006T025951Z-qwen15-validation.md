# Qwen约1B量化模型验证

选择官方Qwen2.5-1.5B-Instruct-GGUF的Q4_K_M文件，参数约1.54B、文件1117320736字节，固定修订91cad51170dc346986eccefdc2dd33a9da36ead9。官方来源：https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF 。

实施前检查：CPU96逻辑核，显示GPU不参与计算，主机三个VE运行槽及VEOS接口可访问，运行可用仍需真实烟测。独立生成qwen2模型入口并重用已构建框架对象，保留35B产物。后续所有构建和CPU/VE执行均使用温度守护；只读取风扇，不修改配置。计划先烟测、三提示完整词表对照，再短输入线程和长输入性能测量。

模型文件已通过SHA256与大小校验。完整加载器编译耗时较长，改用固定上游ABI的小型创建适配器，以extern C明确链接符号，复用已有Qwen2实现；两个独立执行器已链接成功，35B产物未改动。原量化路径三提示最高分词元均8/8一致，但全词表最大误差0.976–2.969、RMSE0.172–0.335，均未过预先设定的0.1/0.01门槛，不能作为通过精度验收的速度。高精度路径前两提示通过，第三提示仍运行。构建CPU峰值81°C达到警告但低于停止线；BMC读取未获得授权，原生可读风扇通道已记录，不能声称观察到BMC策略变化。
