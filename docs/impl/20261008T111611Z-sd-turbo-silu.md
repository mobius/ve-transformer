# SiLU 候选实施

新增src/ve_sd_turbo_silu.c，局部O2/no-fast-math编译，不提高整套ggml优化等级。覆盖生成器仅替换SiLU向量入口：SD_VE_SILU=1选择候选，默认generic保留原实现。检查器显式设置开关并记录到来源报告，重检要求模式匹配。独立测试七样例均通过，最大绝对误差1.24309148e-6，构建CPU峰值72°C，单元CPU61°C、VE43.25°C，风扇97通道无可观察变化。开始ABBA，结果待完成。

## 第一候选拒绝与边界修正

第一次候选在VAE解码出现非有限数值，ABBA停止，不能采用173.790秒的失败进程作为性能数据。补充-1000等极端输入后直接测试复现：-1000错误返回-1000而不是接近零。NCC本机官方帮助指出-fno-fast-math只控制标量数学，默认向量数学不检查参数范围，且默认使用近似倒数替代除法。修正独立候选编译选项：-mvector-intrinsic-check、-mvector-floating-divide-instruction、-fno-reciprocal-math及-fno-associative-math；保持原公式。必须重新构建、边界测试、整图对照，不沿用失败性能。
