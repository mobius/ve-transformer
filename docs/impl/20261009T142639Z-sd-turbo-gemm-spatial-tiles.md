# VAE长空间维度矩阵分块微基准

执行前CPU61°C、VE最高42.38°C，97可读风扇状态无变化；现有NLC OpenMP构建与槽1逐矩阵诊断运行通过。沿用96逻辑CPU、三VE环境，单槽1串行运行，无安装。

依据上一轮真实形状，测试m128/n262144/k1152和m256/n262144/k2304。原实现一次CBLAS调用，候选沿n维分块8192/16384/32768/65536，B输入行偏移和C输出列偏移，原ldc不变。固定4线程，原/候选/候选/原，每臂1次预热3次测量，同一进程固定输入；计时仅矩阵调用，包含候选多次调用成本。

每次完整输出与原CBLAS基线比较、边界哨兵检查，独立主机FP64抽样20位置，最后完整输入不变检查。完整输出比较并非完整CPU标量参考，抽样范围明确记录。编译独立测试限制CPU25%，运行不限制，全程CPU80/85、VE70/75及风扇监控；缺失温度停止。

本轮为独立内核候选，不接入模型，不宣称整图收益，不提交。独立编译、真实VE测试、证据审计已完成。
