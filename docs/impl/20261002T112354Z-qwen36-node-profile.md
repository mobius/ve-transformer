# 迭代018：节点耗时采样

推理入口加入可选--profile节点耗时采样：按算子、源类型与形状聚合，记录调用数和耗时到stderr，生成JSON结果维持原结构。记录不包含提示词、凭据或私人路径。默认不安装回调，正式吞吐不承担采样开销。CPU/VE实际验证待补。

真实CPU 35B模型采样验证正常退出：同提示词、4096上下文、1线程、4步生成，采样开/关词元一致（391及结束标记），248320维×4步logit最大绝对误差0，得到204组分阶段算子报告。温度保护CPU72°C、VE最高40°C，96通道无实际BMC转速证据。CPU未采样生成2.532239 token/s，单次短测不作为最终CPU基准。采样中Q8投影和Q6输出头较明显；这不是VE瓶颈证明，需硬件模型测量后决定优化。
