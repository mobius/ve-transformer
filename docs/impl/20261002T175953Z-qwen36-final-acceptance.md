# 最终优化实现及验收证据

环境：双路Xeon、显示GPU不参与推理、三张NEC VE中使用运行槽1/物理ve0；真实模型已实际执行，不以设备枚举替代运行验证。没有全局安装或风扇配置修改。

测试限定为Qwen3.6-35B-A3B UD-Q4_K_M文本权重、4096上下文配置，FP64累加/F32激活。模型约22.13GB，稠密缓存实际有效载荷14.44GiB（元数据和工作缓冲另计）。不代表视觉、256K上下文或三卡并行已验证。

实现包括复用工作线程、量化块解码、精度一致的状态更新/专家Softmax、NLC矩阵计算，以及16384MiB预算的不可变稠密权重缓存。并行填充在锁内预留预算、锁外转换、锁内发布；保留原回退数学，专家权重不整量缓存。与串行填充测量相比，首次短输入处理由约99秒降到约45秒；同精度未缓存生成由约0.1035到0.5096词元/秒。

最终复核七组缓存性能文件的记录数、重复输出、缓存预算及reserved清零，所有通过；未缓存三次输出一致，四线程配置各与基线一致。25个构建产物SHA256与验收清单吻合。真实模型精度证明为三提示共36步，最大误差0.004189、最大RMSE0.000477；长输入只验证重复一致性，未执行其完整词表CPU参考对照。
