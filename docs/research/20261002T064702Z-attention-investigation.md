# 迭代 008：注意力优化前调查

实施前检查：CPU/NCC/NLC 和运行槽位 1、2、3 可用，温度监督首次读数 CPU 最大 68°C、VE 各最大约 39–41.25°C，低于 70°C 警告及 75°C 停止阈值。无需安装软件，不使用显示 GPU，不改系统设置。

当前 NLC 后端仅加速线性投影，注意力仍执行“头→查询→键→头维度”的细粒度循环。注意力头维度小，频繁短向量运算可能成为瓶颈；这是待分项计时验证的假设，不据代码推断宣称耗时占比。

候选方案：通过 NLC 计算每头的 QK 转置乘积和注意力概率乘 V；利用行跨度直接访问交错存放的多头数据，避免额外打包；先用单头完整分数矩阵降低实现复杂度，明确新增临时内存成本。
