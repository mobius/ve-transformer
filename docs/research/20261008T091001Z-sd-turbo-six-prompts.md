# 六提示整图测量

官方FP32 SD-Turbo、512×512、单步、单VE运行槽1、8个原生计算线程，六提示均逐级通过独立Diffusers CPU参考。见[公开结果](../results/20261008T091001Z-sd-turbo-validation.json)。所有阶段最大相对L2为1.4072540×10⁻⁵，解码最大相对L2为6.5952546×10⁻⁶。六个诊断进程263.239–272.343秒，均值266.828秒；含逐次权重加载、图构建、计算、原始数组与PNG输出，不是常驻稳态秒/图。

实际查看了杯子/苹果、湖畔木屋、织物、帆船和机器人输出；首例红方块此前已查看。物体可辨识，但机器人图没有清晰气球，帆船图没有天空。记录提示遵循的限制，不将数值一致性当作图像质量基准或所有语义都满足。
