# RGB 输出缓冲复用验证

状态：实施中，尚未测量性能收益。

环境预检：x86_64，96 逻辑 CPU，三张 VE1，NCC、ve_exec 可用；设备与 VEOS 存在，实际运行仍需本轮验证。温度监控预检 CPU 64°C，VE 最高 46°C；97 个可读风扇状态未观察到变化，实际风扇策略不能据此断言。

背景：上一轮正式对照热请求 10.458508→10.078768 秒（降低 3.63%）；图像输出 1.162153→0.738460 秒。当前每请求 RGB 缓冲分配并初始化 786432 字节，诊断准备阶段约 0.200 秒，需测量复用的实际效果。

方案：默认关闭跨请求 RGB 缓冲复用，首请求在原输出位置分配，后续请求复用；每次覆盖全部字节。保留请求分配基线，记录实际分配及复用事件。固定 PNG O2、主程序 O0 与既有优化配置。

验证：同构建双请求、六提示词与四步检查；验证 F32 与 PNG，监控温度与显存回收。完成后进行同一二进制 request/resident/resident/request 对照，分别报告冷、热与进程总耗时。未测量不得宣称提升。

报告：当前与所有历史轮数据、一句话结论及下一步方向同时输出；失败与退化保留。

## 实施记录

候选构建已通过；PNG 保持 O2、主程序保持 O0。构建温度 CPU 70°C、VE 最高 46.12°C；97 个可读风扇状态未见变化。新增默认关闭的 SD_REUSE_RGB_BUFFER 开关与逐请求实际分配/复用记录，检查器验证事件顺序与字节数。

首次双请求验证在显存采样器硬件查询前因缺少显式监督标记退出（没有模型性能数据），日志保存在忽略的 build 目录。已在温度守护内部补齐监督标记并重新运行，尚未完成。
