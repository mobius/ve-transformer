# SD-Turbo 移植迭代

目标按上一阶段方案推进官方 SD-Turbo、单 VE、FP32。环境检查：96 逻辑 CPU，三张 VE1 的运行设备/socket 可用；ASPEED 显示控制器不承担推理。初始温度 CPU62°C、VE最高45.62°C，温度监控可用；运行能力须实际测试确认。风扇/策略观测通道计数97，零观测变化，无法证明不可读策略稳定。

先固定官方模型及独立 stable-diffusion.cpp/ggml 来源，建立隔离项目 uv 图像环境和 CPU 参考，逐步验证算子及完整 VE 推理；权重、图像与原始日志保存在忽略目录。未测量不发布性能结论。

## 来源与准备

官方 SD-Turbo 固定为 b261bac6fd2cf515557d5d0707481eafa0485ec2；stable-diffusion.cpp 为 a1ded76da5818803fca97a3b433669ef727d32cf，独立 ggml 为 89c4413f5da6fb20cc796f16033d37f129be81fd。采用官方 Diffusers 分组件 FP32 权重目录，供两套实现读取；每文件校验官方 LFS SHA256 或 Git blob，再生成本地来源清单。原始配置可能含上游创建者路径，只保存在忽略目录，不进入公开文档。

参考环境位于 build/venvs/sd-image，固定 torch2.8.0+cpu、Diffusers0.36.0、Transformers4.57.6 等；不改变 LLM 环境。源码、权重与依赖下载尚在推进，未进行图像推理测试。

## 编译与精度适配

原始 NCC 构建在 GGUF 模板读取器的 O1 优化阶段发生编译器 SIGSEGV，构建失败，最高 CPU72°C，VE45.38°C，未触发温度停止。局部构建配置将读取器设为 O0；不降低图像算子的数值标准。首次生成补丁范围断言发现同名分支不唯一，已将替换限制到卷积函数及普通生成分支，避免修改不相关路径。

发现原始二维卷积会将 FP32 输入块整理为 FP16，故生成独立源码替换，仅令 FP32 卷积保持 FP32；原始框架与 ggml 工作树保持不变。另为测试增加固定初始噪声输入及嵌入/最终潜在数组导出，精确尺寸、非有限值和读写失败均拒绝；开关默认关闭。这些适配当前仍待构建与实际数值验证。

CPU 参考导出单步/四步时间步、噪声、文本嵌入、每步 U-Net 输入/噪声预测/潜在表示和 VAE 输出。导出数组按 NCHW 连续 FP32；原生维度以最低连续轴优先，比较前明确轴顺序，不用随机数种子相同替代初始数组相同。首轮采用通用卷积工作区，运行前检查分配预算，测量后决定分块，不提前宣称分块优化完成。

官方三组件全部 FP32，实际参数 1,289,952,427，权重有效载荷 4.80545 GiB（不含工作区），来源摘要已生成。参考环境安装完成。GGUF 读取器降为 O0 后仍发生 NCC 编译器 SIGSEGV，已生成显式 constexpr 两分支适配，待重试；后台元数据管理单元也降 O0，算子精度不变。

首次 CPU 单线程 512×512 参考与受限编译并行期间触发 CPU85°C 停止，两套温度守护均终止自己的任务；VE最高45.25°C，未完成该参考或该次编译，不能作为正确性结果。随后改为串行进行参考/编译，参考采用25%任务占空比，并记录受限耗时不是正常 CPU 性能基线。没有改风扇或阈值。

## 首个 CPU 参考完成

串行25%占空比的 FP32 CPU 单步512×512参考已完整完成，最高CPU79°C、VE45.12°C。初始噪声、文本嵌入、时间步、噪声强度、U-Net输入/输出、最终潜在表示与VAE输出均导出并校验有限值；图像保存在忽略目录。占空比包含在报告中，阶段耗时不是未受限CPU性能基线。参考只覆盖首个公开提示，目前不称为六提示质量或四步验收。

发现框架默认设备选择不自动选择 BLAS 设备，且设备标签与物理执行位置是不同概念：原生VE进程中的CPU后端依然运行在VE，不是主机卸载。实际推理拟显式使用NLC BLAS调度及本地原生后端回退，并验证矩阵阶段确实被覆盖。SD-Turbo噪声预测为epsilon，必须显式设置；关闭提示引导在两框架参数表示不同，须使实际仅使用正向条件这一计算一致，不能照搬数值参数。时间步/噪声强度直接与固定CPU参考比较。
