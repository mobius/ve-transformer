# Qwen3.6 原生 MTP 继续实施

本轮继续原生 Qwen3.6 MTP。用户已授权主机执行；重新检查 96 CPU 逻辑线程、ASPEED 显示控制器、三张 VE，三个运行槽的设备和 VEOS socket 可用，实际运行仍须烟测。复用固定框架的独立 MTP 图，不改上游源码。

共享张量当前取得输出权重、词嵌入和最终归一化。MTP 文件首先采用 F32 以复用现有高精度稠密和专家计算路径；量化 MTP 将作为后续性能选择。官方来源固定提交不变，目标量化来源的准确官方提交尚无法确认，需词表、配置和张量兼容检查。


## 下载与目标烟测进展

官方选定源 22 个张量下载并组装完成，BF16 有效载荷 3.468 GiB。恢复下载 CPU 峰值 82°C、VE 峰值 57.75°C；初次受 85°C 停止保护，后续串行完成，没有放宽阈值。

共享前执行器仅普通目标模型：运行槽 1、4 线程、8 GiB 缓存、原始一词元输入、强制生成 4 词元，同进程两次输出一致；约 0.195 词元/秒，仅烟测，不能作为最终 MTP 对照。温度 CPU 78°C、VE 61.88°C。执行器及清单保留在 build/qwen36-mtp-pre-share。

当前模型转换已产出 F32 MTP-only GGUF，23 个张量，约 7.45 GB（合并专家 gate/up 拆成两项）。进一步用目标模型的量化词嵌入和输出层替换 GGUF 的共享张量：逐项核对词表与配置、最终归一化，并在写出后检查共享量化张量逐字节一致。运行时两模型共用这两个已验证相同的张量指针，使 FP64 缓存也复用，而非为相同输出层额外缓存约 4 GiB。官方训练 MTP 层及自身归一化保持独立。

最终目标与 MTP 同配置计划为 8 工作线程、上下文 512、缓存预算 16 GiB；实际保留、卡内分配与性能均须测量。已有目标共享匹配不能证明目标所有量化张量对应官方提交相同，保留来源限制说明。


## 兼容性与写出修正

官方转换与量化目标的 padding 设置不同，官方显式 add_eos_token=false 而目标未存此项。词表内容/类型及其余目标键一致。单序列草稿没有填充输入；准备脚本保留验证一致的词表 ID 映射，统一采用目标完整 tokenizer 元数据，拒绝其它未知差异。关键配置和 output_norm F32 值逐项相等。

首次写出失败是固定 GGUF writer 的 write_tensors_to_file 已内部写 tensor-info，先显式写一次会触发状态错误。已修正顺序，重跑只准备/验证阶段，不重复下载或 F32 转换；尚须确认最终写出与原生加载。借用相同张量避免 FP64 权重缓存重复，但加载缓冲区的原始共享权重副本仍占内存，不能宣称消除了所有重复占用。

## 编译温度停止与任务限载

修正接口后的首次重编译触发温度保护，监控采样峰值 CPU 87°C、VE 58.62°C，任务已停止。85°C 为停止策略阈值，0.5 秒采样可能观察到已超过阈值的瞬时值，不隐瞒此次越限。冷却后 CPU 约 68°C。

新增项目内 scripts/cpu_duty.py，对本次编译任务及其后代进程执行 25% 占空比运行，其余时间暂停；不安装软件、不修改系统 CPU/风扇设置。按进程组、后代关系和启动时间验证信号对象，子任务仍处于温度守护进程组，可整体终止。测试已验证嵌套后代暂停、退出码传递及守护取消不留下运行后代。构建监控采样缩短到 0.2 秒，停止阈值保持 85°C；实际后续峰值须测量。

25% 编译占空比构建完成，CPU 峰值 78°C，VE 峰值 57.62°C，97 个风扇/策略可读通道无观察变化。保持 O3 与已有高精度数学内核，编译限载不作用于推理。当前完整验证使用 8 个 VE 工作线程、16 GiB 缓存预算、上下文 512，覆盖三个提示的独立 CPU 已保存贪心序列、重复请求、草稿扰动回退、自然结束和跨 128 预填充批次边界。未完成验证前不宣称提速。


## 部分验收与后续性能协议

两个提示已完成，每个 12 词元、同进程两次重置，均与普通 VE 和独立 CPU 已保存参考一致。数值提示热态 0.593304 -> 0.780130 词元/秒，1.3149 倍，接受 6/8；编码提示 0.599913 -> 0.883025，1.4719 倍，接受 7/7。仅为固定 12 步短测，数值提示强制计数可能超过自然结束，不作为一般性能结论。实际 FP64 权重缓存保留 14.7363 GiB，未测物理 HBM 峰值。

完整功能验收通过后再用编码提示固定 16 词元、每进程 3 次请求，按普通/MTP/MTP/普通（ABBA）顺序测量，剔除每进程首次请求后各保留 4 个热态样本。对照与 MTP 维持 8 线程、512 上下文和 16 GiB 缓存，逐个请求检查贪心序列一致，绑定同一执行器和两个模型 SHA。测生成、预填充、草稿、验证、追赶和回退耗时，并保留模型加载成本；不会把生成阶段收益冒充首次启动端到端收益。
