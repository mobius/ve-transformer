# 单VE注意力矩阵乘法优化迭代

实施前确认96逻辑CPU、ASPEED显示控制器与3个VE运行槽可访问，NCC/NLC可用；温度守护读取成功，BMC风扇状态不可用。设备枚举不作为运行验证。无需安装依赖。

定位：NLC现有投影路径只接受F32/量化权重及单批维度，排除注意力的F16多头矩阵。独立profile提示输入阶段该路径是热点，但采样耗时不代表正常运行。

候选：将F16多头矩阵按头/批分给框架线程，支持头数和批维广播、步长寻址，转换到现有FP64 NLC矩阵乘法。右输入先进行与固定上游一致的F16舍入，再展开计算。动态注意力数据不进入权重缓存。通过独立宏与独立二进制保留常驻基线。

验收：使用独立标量参考覆盖分组头映射、批广播、非连续布局、不同维度与线程数；三提示24步全词表对照，连续/长输入生成结果与已验收参考一致；关闭profile测同轮基线/候选。全部构建及硬件测试用温度守护，记录可读风扇，不调整配置。未经验证不宣称性能提升。
