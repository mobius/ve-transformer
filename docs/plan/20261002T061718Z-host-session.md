# 迭代 004：直接主机执行路线

由用户在主机侧改变会话执行权限。若使用 CLI，在项目目录执行：

```bash
codex resume --sandbox danger-full-access --ask-for-approval on-request
```

恢复选择器中选择本项目会话；若该会话无法由 CLI 恢复，可在项目目录启动：

```bash
codex --sandbox danger-full-access --ask-for-approval on-request
```

该设置取消 CLI 本地沙箱限制，访问范围包括主机其他资源，仍保留按需审批策略。若托管启动器强制权限配置，须在启动器一侧调整；仅在聊天里授权不会改变内核设备隔离。无需提供密码、私钥或 API 凭据。

环境切换后先运行项目环境检查和小规模三卡验证，再执行规模扫描，不假定权限设置成功。
