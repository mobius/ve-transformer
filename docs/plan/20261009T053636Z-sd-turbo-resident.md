# SD-Turbo 三组件常驻候选

上一轮完成全节点连续采样5.3223GiB/48GiB、退出恢复128MiB。实施前检查CPU96线程、ASPEED显示设备及三张VE1；运行槽必须在授权环境及温度保护中执行确认。前一目标轮为实际测量进展。

将CLIP/UNet/VAE生命周期统一为open/run/close，权重懒加载一次。每请求工作区独立，UNet请求后释放计算调度器，CLIP/VAE原本逐compute释放。默认重载；显式常驻模式及本地请求清单供同二进制对照。先两个相同请求验证复用，再多提示/四步和ABBA；保持串行、CPU80/85与VE70/75阈值。尚未宣称性能或常驻完成。

## 候选代码与验收入口

CLIP/VAE新增open/run/close并用unique_ptr按析构顺序清理runner后再清理backend，原一次性函数保留兼容包装。UNet新增release_compute，保留权重而释放请求调度器。main默认按请求重载，环境SD_RESIDENT_WEIGHTS=1显式保留三组件。请求清单限定2至16个（原单请求仍支持），每行五个tab字段：提示、噪声、sigma、独立轨迹目录、PNG路径；原固定参数限制保持512/1或4步/8线程验证路径。

tests/check_sd_resident.py验证官方权重/CPU参考/构建全哈希；同进程执行有序请求，逐请求比对独立参考、噪声与时间步，并要求CLIP/UNet/VAE实际NLC矩阵分配。重载每请求3次加载，常驻首请求3次、后续0次，加载标记、weights_load计时记录和线程池创建三路一致；保存全部原始数组和PNG哈希供后续同二进制按位对照。候选编译正在温度保护、50%占空比、4CPU核心和-j1下执行，未与推理并行。

## 温度终止信号路径修复

内存采样器以独立进程组启动命令；补充SIGTERM/SIGHUP处理，把外层温度守护的终止转入finally，立即结束命令组，以在外层两秒强制终止期限前清理。非硬件模拟SIGTERM验证子进程被终止并保存失败记录。上一轮成功模型测量没有触及温度停止线，保留原采样器SHA；后续本轮硬件测试使用修正版。

追加非硬件中断测试：命令再创建一个子进程，模拟温度守护SIGTERM后父命令与其子进程均停止，确认清理覆盖后代。重载/常驻ABBA脚本已准备，每组两个独立进程、每进程默认两个有序请求；要求每请求所有FP32轨迹与PNG跨四次运行按位一致，并记录每轮连续节点内存。

复测build/results/20261009T060243Z-sd-resident仍在manifest_row后SIGSEGV，替换字符串流未解决问题，不能将根因确定为字符串流。继续加fields_ready/field_found/field_copied标记定位容器写入与子串创建。当前只有完整编译通过，常驻推理仍未进入模型加载，尚无性能结论。

## 独立复现与逐字符扫描

逐字段标记证明fields容器已构造，崩溃在首次line.find之前完成输出之后发生。独立NCC C++11/O0/no-inline小程序读取29字节TSV，输出size=29后在find(char)复现SIGSEGV；不含模型/ggml。将find改为逐字符扫描，得到分隔符位置5、字段复制长度5，实际VE运行通过。入口采用相同扫描并保留五列/空字段/回车规则，正在重编译。相关原始日志request-parser-probe-supervised.log与request-parser-scan-probe.log在build，CPU最高65/66°C、VE43.25°C。首个复现命令漏监督标记，限速脚本拒绝启动编译；已补齐标记后实际复现，未跳过监控。现有证据确认该操作可独立复现，但未判定编译器或运行库的底层根因。
