# im2col 循环优化迭代

承接SiLU/Softmax优化，当前单步VAE图执行约43秒；旧算子计时im2col约38秒，是下一计算瓶颈。实施前枚举96逻辑CPU、ASPEED显示设备和三张VE1，NCC/VEOS可用；槽1原生24组Softmax实际通过，CPU59°C、VE43°C，温度可读。仅槽1有本轮运行证明。

候选维持按输入通道分给线程的所有权，将输出列改为最内层较长循环，提取边界并分开填零与复制。仅二维、F32、连续布局、正步幅/膨胀且非负填充；其他情况回退原实现。独立C文件O2，无浮点运算变更，要求逐元素精确相等；不改vendor、LLM后端或共享模型头文件。

先测试批量、奇数尺寸、1/3卷积核、步幅/膨胀/填充及向量尾部，再通过ggml图验证二维激活和一维/非连续布局回退。集成阶段记录实际优化/回退节点数。性能对照固定SiLU/Softmax ve与8线程常驻池，仅切换im2col，采用同二进制ABBA与独立CPU参考，额外四步及六提示；不从编译选项提前推断提速。

所有重型任务串行温度监督，CPU80/85°C、VE70/75°C。可读风扇状态继续观察；sysfs零转速与BMC不可读不能解释为实际转速/完整策略。阶段耗时包含加载及诊断，不是常驻稳态指标。后续还需测真实HBM、工作区再设计权重常驻；本轮不会把完成一项内核等同整体效率目标完成。

## 构建与直接验证

候选构建完成，复制/填零循环实际向量化，CPU峰值70°C。16组数据复制独立按位/尾部测试通过，CPU60°C；三组ggml图按位对照和输入不变检查通过，实际分派记录优化1、回退2（一维、批量带间隔布局），CPU64°C；上述VE峰值均43°C。开始同二进制原im2col整图基线。候选要求输入输出缓冲独立，不声明部分重叠或原地复制支持。

## ABBA 完成，扩展验证待完成

同二进制固定两项激活优化及8线程常驻池，仅切换im2col：整进程131.625418→92.941631秒，延迟下降29.3893%；三网络图执行59.276854→20.511851秒，下降65.3965%；VAE图执行50.818844→13.678242秒，下降73.0843%。权重加载58.920226→59.005753秒，无收益。四次各五项CPU比较通过，首个候选与控制的所有原生F32诊断数组逐字节一致。CPU峰值82°C触发警告未达85°C停止线，VE峰值51.125°C；可读状态无变化但实际风扇转速和完整策略不可确认。四步及六提示仍待完成，整体效率目标继续保持，包括实测HBM和权重常驻等后续工作。

## 内存查询预研（非峰值验收）

本机veosinfo3 3.6.0提供ve_mem_info，但开发头文件未安装。已在忽略的build目录核对[SX-Aurora公开绑定](https://github.com/SX-Aurora/py-veosinfo/blob/49d517386e085ee3328f4548e9fadbd06c6aae26/veosinfo/_veosinfo.pyx)，源码仅调研，不安装全局环境。独立温度保护的只读探测返回三个运行节点总量50331648 KiB（48 GiB），使用+空闲等于总量；采样时槽1使用5580800 KiB，另外两槽131072 KiB。该探测使用额外大的输出缓冲，尚未完成完整接口/受控分配交叉验证，只是单次读数，不是物理HBM峰值，不据此采用权重常驻。后续需用明确分配量验证统计域和采样峰值，并区分全节点内存与单进程贡献。
