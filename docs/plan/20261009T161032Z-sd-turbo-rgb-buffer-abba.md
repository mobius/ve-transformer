# RGB 缓冲复用正式性能对照

状态：准备测试，未测量本轮收益。上一轮候选 62 项 CPU 参考检查通过，10 请求浮点追踪与 PNG 和上一构建一致。

方法：同一二进制、相同检查器，request/resident/resident/request 四臂；每臂 case 0 的一冷三热、一步 512×512 FP32。固定权重与分词器常驻、通用 8/VAE 矩阵 4 线程、GELU/广播/行整理/8192 矩阵分块以及 PNG O2。每模式六个热样本作为主指标；冷加载与进程总时间另列，缓存未控制。默认保持按请求分配。

所有硬件执行和 CPU 数值审计受温度守护，观察可读风扇与节点内存回收。独立审计重新检查既有 62 项和当前 80 项 CPU 参考，并要求实际复用事件和所有 F32/PNG 字节一致。完成后汇总当前及历史轮性能，保留退化结果。
