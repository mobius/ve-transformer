# 下一阶段图像模型实施计划

先完成本轮 MTP 常驻功能验收，再开始图像实施。首个目标 SD-Turbo，单 VE 槽 1、FP32、512×512、固定公开提示和导出的初始噪声、单步与四步；速度和质量都必须测量。256×256 只是排错。

| 阶段 | 实施与交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 环境/来源 | 检查硬件和温度；固定官方权重/框架提交；项目内 uv 图像参考环境；导出容量清单及 CPU FP32 参考 | 配置、调度、张量加载与来源哈希一致；无全局安装 |
| P1 算子与去噪核心 | 在隔离源码中适配 NEC 编译器；NLC SGEMM、分块卷积、归一化、激活、上下采样和注意力；先移植 U-Net 单步 | 实际尺寸及非整块边界数值通过；声明此阶段文本编码/VAE 可暂用 CPU，只是部分移植 |
| P2 完整神经网络 | 文本编码器、U-Net、VAE 解码均在 VE；权重/工作区常驻，调度更新也在 VE | 与 CPU 同一文本嵌入、初始噪声、时间步逐级比较；单步和四步端到端通过 |
| P3 性能优化 | 分项测时和分配峰值；按占比优化矩阵分块、卷积工作区、注意力分块；常驻重复不同提示 | 正确性保持，交替基准可复现；测量后才采用优化 |
| P4 扩展 | 三卡先做独立图像任务；再选现代 DiT，之后才考虑短帧视频 | 单卡运行稳定，峰值内存与温度有余量，关键算子无功能缺口 |

精度门槛先固定：用 CPU FP32 参考，同一导出输入，算子归一化 L2 误差 <=1e-4；核心单步输出 <=1e-3、完整潜在表示 <=1e-2，像素差异记录而不要求 PNG 字节相同。定义误差为 ||候选-参考||2/max(||参考||2,1e-12)，同时记录最大绝对误差与非有限值；参考接近零时补看绝对误差。四步误差不能靠放宽阈值掩盖错误；如初次合理数值顺序差异超限，先归因并留档复核，不自动提高阈值。质量采用固定至少六组英文提示，覆盖简单物体、颜色关系、风景与材质，由同一噪声对照参考；小样本图像差异不称为模型质量基准。

性能分别记录加载、首次请求、热态文本编码、每步去噪、VAE、完整请求、主机/VE 传输及可测内存峰值。首轮不预定秒/图，不做无 GPU 实测的倍数比较。完整请求每配置至少两进程、每进程一次预热加三次计时；候选优化用交替顺序比较。温度沿用 CPU80/85°C、VE70/75°C，监控失效停止；观察可读取的风扇/策略，不修改配置。

停止条件：必需算子无法执行或数值失败则停在该阶段排错；容量预算超出保守单卡可用值则先减小工作区/分块，不直接尝试高分辨率；守护停止则冷却、重新检查，不绕过阈值。关键算子与完整请求均无值得保留的性能收益时保留验证入口，不声称加速，推迟视频。预计时间需 P0 编译/算子清单完成后再估计。
