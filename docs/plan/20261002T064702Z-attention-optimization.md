# 迭代 008：注意力优化计划

1. 加入可选分项计时接口，量化线性变换、注意力、归一化和临时分配耗时；标准基准不启用分项计时，避免仪器开销混入对照。
2. 新增独立 fast 后端，以 NLC 执行每头两次矩阵乘法；保持基础与线性 NLC 后端可复现。
3. 做稳定 Softmax、因果/双向掩码验证，检查非整齐维度和最小形状，维持原独立 float64 误差阈值。
4. 三卡顺序对照线性 NLC 与 fast 后端，记录多次重复的平均、P50/P95、温度和新增内存。若小形状出现回退则明确报告或选择受实测支持的分派条件。
5. 在 PyTorch 权重和两层小模型验证新后端；按收益再评估临时内存复用，不一次叠加未经测量的变化。

所有实际硬件测试使用温度监督；70°C 警告、75°C 停止，不提升阈值，不开展长时间压力测试。过程持续写 research/plan/impl/architecture，并审计可提交内容。
