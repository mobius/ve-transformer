# im2col 256形状扩大模型派发

实施前CPU60°C、VE41.50°C，运行接口可用，上一轮实际对象256形状微基准32次按位检查通过，97可读风扇状态无变化。继续CPU80/85、VE70/75保护，串行编译50%占空比、限定CPU0–3。

新增默认关闭rows_256模式，在既有512形状基础上扩大至已测N1、256×256、3×3、256/512通道、单位步长/膨胀、填充1、实际8线程；内核源码/编译属性保持不变。保留channels和rows（仅512）模式。派发与范围标志都从原生日志核验，VAE rows_256预期15候选/25原节点，rows仍8/32；其他未测形状不派发候选。

本轮模型性能与正确性尚待验证，微基准53.41%/44.96%不能套用为整图收益。下一步构建核验实际对象不变，双请求/六提示/四步CPU参考后，以同新二进制rows/rows_256/rows_256/rows比较新增收益，要求输出字节完全一致。不安装、不调整风扇、不提交。
