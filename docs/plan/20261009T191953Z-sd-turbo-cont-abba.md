# CONT 同程序对照（第 77 轮）

使用同一个已验证二进制，按 generic、ve、ve、generic 顺序，仅切换 SD_VE_CONT。每组同一提示词、512×512、一步、一次冷请求及三次热请求；随后独立 CPU 数值与 PNG 审计。所有测试温度监控失败即停止。

首次 ABBA 因 CPU 达到 85°C 被保护终止（VE 峰值 63.12°C），未完成最后基线组，不能作为正式收益。失败原始目录保留，日志与脚本快照保存于忽略的诊断目录。下一次各组开始前读取全部温度，等待 CPU≤65°C、全部 VE≤55°C 持续 10 秒，最长等待 300 秒；降温在计时进程外进行，不节流 VE 或修改风扇。
