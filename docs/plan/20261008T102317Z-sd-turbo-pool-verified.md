# 线程池验收后的优化方向

首轮常驻线程池已通过单步ABBA和四步数值验收，推荐在已验证流程显式传入--threadpool persistent；保留disposable作基线，默认未切换。当前可用计时和二进制保存供下一轮对照。

下一轮先进一步拆分VAE与UNet通用算子的耗时。VAE图执行仍约84.36秒，是候选图执行中最大的部分；根据实际卷积输入打包、归一化、布局变换占比，再选向量化或内存布局改动。不得用后端总时间推断某一算子的占比。

另记录实际VE内存预算和跨请求状态，再设计权重常驻；每图约59.68秒加载为可测开销，但未测内存峰值，不能预报该项收益。保持所有编译和重型任务串行、温度守护与风扇观察；每项独立ABBA与CPU数值对照。
