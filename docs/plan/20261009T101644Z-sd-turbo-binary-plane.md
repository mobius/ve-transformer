# 连续平面广播加乘候选

上一轮实测VAE70/85 ADD、30/30 MUL符合连续平面标量广播安全条件，双请求10项CPU检查；本轮据此实现独立FP32长向量加乘，不修改其他计算或线程数。

环境：宿主96逻辑CPU、ASPEED显示、三VE槽设备及VEOS套接字可见，统一8线程前轮实际执行。实施前温度/风扇守护查询进行中；归档旧构建保留。重型构建和测试串行，构建50%CPU占空比，独立测试编译25%。

候选仅接受连续F32主输入/输出、广播前两维1，输出与广播值分离，主输入输出分离或完全一致。按通道/批次分配平面，独立C O2内核，严格浮点；原地与独立缓冲分支分别处理，不违反restrict。其他布局或别名回退原函数。显式开关默认generic，记录ADD/MUL实际分派计数。

验收：尾部/原地/独立缓冲及特殊值独立检查；实际分派与fallback、独立CPU双请求、六提示/四步；随后同二进制ABBA，未测量前不宣称收益。持续温度/风扇/内存守护，每轮报告。无安装、风扇修改或提交。

## 初次构建与边界/图验收

预检CPU63°C/VE42.5°C、节点128MiB。构建通过，四条原地/独立缓冲加乘循环NCC报告向量化，最高CPU67°C/VE42.5°C。独立标量oracle禁向量，448组长度/特殊值/原地/独立缓冲/尾部保护通过，有限值按位一致、NaN只验证分类不要求载荷相同。12组GGML真实图通过，4次候选、8次非连续/非标量回退；输出按位正确。首图测试未将需保留输入标为输出，分配器合法复用输入导致保护断言失败；修正生命周期标记后重跑通过，保留失败日志，内核未改。图与单元CPU59°C、VE最高42.75°C；每次97风扇状态通道无变化。随后启动完整模型候选双请求；尚待数值和正式性能验收。

## 参考验收错误与补测

首完整模型原生双请求完成，分派符合预期，但新增检查器将CPU参考rows字典覆盖成分派列表，数值验收前失败，summary保持false。更名dispatch_rows并核对参考字典只有一次赋值后重跑；内核/二进制不变，保留原失败日志。失败CPU71°C/VE51.12°C，97风扇通道无变化。独立边界验证扩展至65536/262144元素（实际最大512×512平面），504组全过，CPU66°C/VE44.5°C。不得把失败热请求计时作为正式收益。

## 完整双请求通过

修正检查器变量后新双请求10项独立CPU阶段比较及实际分派数量核验通过。冷/热83.733990/13.938414秒；热请求VAE ADD0.078702秒、MUL0.003510秒。与不同诊断进程的旧数据仅作定位比较，正式同二进制ABBA尚未执行。最高CPU77°C、VE50.88°C，97风扇状态通道无变化；构建与修正版测试均归档。随后六提示验证启动，四步及ABBA仍待完成；不默认启用。

## 六提示与重叠回退通过

六提示30项CPU阶段检查及实际分派数量通过，热请求13.933524–13.978102秒，CPU77°C/VE53.62°C；97风扇状态通道无变化。真实图扩展到16组：6次候选、10次回退，其中2次明确广播值与输出重叠而拒绝候选（原路径单线程避免跨线程别名读写）；输出独立按位对照通过。特殊重叠fixture使用零值，验证分派拒绝与正常完成，不宣称任意重叠图语义。最高CPU63°C/VE48.62°C。随后四步双请求启动；正式ABBA未启动。
