# VAE空间分块扩大真实形状验证

执行前CPU59°C、VE最高41.38°C，97可读风扇状态无变化，无模型/编译进程。前轮单槽1真实运行及NLC可用；沿用96逻辑CPU、三VE环境，单VE测试。

保留前轮快照，本轮使用独立extended文件，扩大到六种真实VAE形状：128/262144/1152，256/262144/2304，512/65536/4608，256/65536/2304，256/65536/4608，128/262144/2304。固定4线程，每形状8192/16384/32768/65536分块分别ABBA，每臂1预热3测量；计时包括所有CBLAS调用。

384次完整输出对原BLAS基线比较、7680个独立主机FP64抽样、边界哨兵及完整输入不变检查。只做内核候选，未接入模型，无整图收益结论。编译25%CPU，运行不限，持续CPU80/85、VE70/75及风扇监控，读数缺失停止。不安装、不修改风扇、不提交。

依据各形状收益和真实调用数决定接入范围，退化形状保留原实现。运行及审计已完成。
