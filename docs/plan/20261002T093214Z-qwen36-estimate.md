# 迭代013：现代模型估算后的验证顺序

1. 温度与风扇监督下，单VE测试超出缓存的大矩阵向量计算与权重读取；先测float32，再做分块4位解码，扫描线程数，记录带宽、延迟、温度、风扇变化。
2. 用可管理的小模型实现增量生成、RMSNorm、RoPE与门控前馈，并对照固定版本CPU参考，检查逐词元输出和长序列状态。
3. 用小尺寸合成配置验证Gated DeltaNet循环状态与混合层；MoE另验路由、专家读取和共享专家。
4. 固定Qwen3.6版本，核算权重/工作区/缓存峰值，先文本短上下文，再扩大上下文。27B结构较简单，35B-A3B有更好吞吐潜力但移植更多。
5. 报告预填充时间、首词元延迟、稳态生成速度、峰值内存和精度；随后才评估三卡并行。

本轮不下载大型权重，未开展上述实施；不能用排期预算替代性能验收。
