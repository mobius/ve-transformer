# 迭代 009：分设备保护与风扇观察

1. 温度监督默认 CPU 80/85°C、VE 70/75°C；保留旧 warn/stop 参数显式覆盖两类设备的兼容用法。
2. 采样可读 fan RPM、PWM 数值/模式/温度源/曲线/时间常数及 VE 风扇通道，服务状态每 5 秒采样。风扇读取缺失标记不可用，不用不可用 RPM 决定温度安全；温度读取失败仍停止。
3. 加入 post-seconds 参数，在任务结束后继续只读采样以观察冷却期；不为了观察风扇刻意制造热负载。
4. 在 fast 框架验证及短时分项计时期间观察前、中、后变化，并明确区分“可读控制值无变化”与“实际风扇策略无变化”。

不改风扇或 BMC 配置，不扩大 sudo 权限。若用户提供真实 BMC 数据，另行对照，不能使用 0 RPM 或活跃服务填补观测缺口。
