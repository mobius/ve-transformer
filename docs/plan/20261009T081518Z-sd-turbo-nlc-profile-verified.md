## 独立探针具体验收设计

冻结八种真实尺寸及行跨度，先核验公开来源SHA。按每种形状顺序执行原顺序库及OpenMP库1/2/4/8线程，每组独立进程且温度/内存监控连续；实际线程数必须在VE并行区域内核对，不把环境变量当运行证明。用确定性FP32输入，原CBLAS行优先N/T参数与真实行跨度，约束全部矩阵内存总和不超过项目规定上限，检查整数与大小溢出。无需加载完整模型。

每组一次预热、三次计时，计时仅覆盖SGEMM。每次输出固定边界/内部采样点，由主机独立FP64算术重算并核对，最后检查完整输出有限性；采样不是完整数值证明，必须明确点数及误差。输入生成、点输出与参考检查不纳入核计时；同一形状各库输入与坐标固定。除kernel均值外记录进程耗时和温度/风扇，防止只报告线程设置或理论速度。

新探针命名独立于图像构建，编译仅在build目录内、温度守护下的低占空比单任务；不修改当前框架源、默认链接或风扇策略。微基准通过后才接入完整图并重跑CPU参考/多提示/四步及性能对照。
