# 迭代 012：resident-single-ve

仅使用运行槽位1；先旧执行器冒烟及分项测量，再实现一次加载全部8块权重的常驻单VE进程。每步只传递嵌入特征、返回最终特征，模型计算仍同float32、GELU与局部窗口，不增加生成缓存。容量有界工作缓冲区复用，保留旧接口。验证更换输入/长度、多轮生成、局部窗口边界、退出/异常/超时，再同模型同16词元旧/新对照，观察温度风扇。

本轮单卡常驻与完整生成对照完成。线程1/2表现接近，默认1而不据短样本断言2最快。增加工作量匹配CPU参考，证实在此案例约1.36倍CPU稳态速度。尚未实现KV生成缓存、嵌入/头在VE、AVEO共享内存或更大模型；后续先评估更长输入的计算/通信与缓存收益。
