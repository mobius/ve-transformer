# 迭代 002：三卡验证计划

实施前判断：CPU 可运行，VE 编译可行，当前沙箱不暴露运行设备。依照只读参考查明正确启动方式后，先修复探测与验证入口，不基于未取得的 VE 性能数据进行优化。

1. 按 /dev/veslotN 发现运行槽位，检查目标字符设备权限及 VEOS socket，不硬编码 sysfs 到槽位的映射。
2. 在设备可见的主机终端执行 bash scripts/validate_ve.sh 1 2 3；先 CPU 正确性检查及 VE 编译，再依次运行各卡双向/因果数值对比和层内基准。
3. 结果输出到 build/results，逐次记录实际数据，不使用历史项目的数字代替本次结果。
4. 三卡基线通过后再评估 NLC 单精度矩阵乘法及不同规模，保留当前 C 实现作为数值对照。

不尝试绕过会话隔离，不改系统服务，不安装全局软件。当前执行限制需要由可暴露 VE 设备的运行环境解决。
